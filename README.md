# 🛠️ bash-toolbox

Collection de scripts bash construits pour automatiser des tâches quotidiennes et consolider mes bases en shell scripting.

## Projets

| Projet | Description |
|---|---|
| [directory-bookmarks](./directory-bookmarks) | Marque-pages de répertoires pour naviguer instantanément |
| [project-setup](./project-setup) | Génère la structure de base d'un nouveau projet selon le langage |
| [backup-rotate](./backup-rotate) | Sauvegarde avec rotation automatique des archives |
| [file-organizer](./file-organizer) | Range automatiquement les fichiers par type |
| [log-analyzer](./log-analyzer) | Rapport de synthèse pour fichiers de log |
| [sysmonitor](./sysmonitor) | Surveillance CPU/RAM/disque avec seuils configurables |

Chaque dossier contient son propre `README.md` avec installation et exemples d'usage.
